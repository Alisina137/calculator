# Privacy Policy — حساب فارسی / حساب دری

Last updated: 2026-09-22

## Summary

The MVP is designed as an offline-first calculator. It does not require an account, backend service, advertising SDK, payment system, or cloud synchronization.

## Personal information

No personal information is required to use the MVP.

## Data stored on the device

The application stores only data needed for local functionality:

- calculation history,
- current calculator draft,
- calculator mode and angle preference,
- language and numeral preference,
- appearance preference,
- haptic preference.

This information is stored locally on the user's device.

## Network use

Primary calculator functionality does not require network access. Percentage, discount, scientific calculations, unit conversion, age calculations, date calculations, settings, and history are designed to work offline.

## Calculation contents

The application does not intentionally transmit calculation expressions, calculation results, entered dates, or financial amounts to a server.

## Analytics

The MVP does not include an analytics service. If privacy-conscious analytics are introduced in a future version, calculation operands, results, user-entered dates, and financial values must not be included in analytics events.

## Accounts, payments, and advertising

The MVP has:

- no user accounts,
- no subscriptions or paid feature restrictions,
- no payment processing,
- no advertising SDK.

## Clearing local information

Calculation history can be cleared from the History screen or Settings. The application asks for confirmation before clearing all history.

## Future changes

If future versions introduce cloud sync, analytics, currency-rate services, accounts, payments, or other network services, this policy must be updated before those capabilities are released.
